# Luxo

**Build APIs at the speed of light**

A schema-first Go framework with binary protocol, field selection, and built-in encryption.

---

## Luxo 是什么？

一个高性能、Schema 驱动的 Go 框架，用于构建现代 API。支持二进制编码和客户端按需字段选择。

## 核心特性

- **Schema 驱动** — 定义一次 API 契约，其余全部生成
- **二进制协议** — 开箱即用的紧凑、高速传输格式
- **字段选择** — 客户端只请求需要的字段，减少传输体积
- **内置加密** — 字段级端到端加密，无需额外中间件
- **代码生成** — 从 Schema 生成 Go 服务端桩代码和客户端 SDK
- **极致性能** — 为低延迟、高吞吐场景设计

## 快速开始

```bash
go get github.com/lintianyao/luxo
```

*即将推出 — Schema 定义、代码生成、服务端搭建指南。*
